# Workouts (added 2026-11-09)

## Decisions made by the owner

- Workouts can be logged, cycling above all, and the calories burned are deducted from the day's calories.
- Workouts are typed in by hand; nothing is imported from Strava, Garmin or other trackers.
- The assistant (a later step) can help work out the calories from a description of the workout.

## Calls made in design (told to the owner, not each confirmed)

- A workout has an activity, minutes, an intensity (easy, moderate, hard), calories, and an optional note. A calorie number the user types (for example from a bike computer) is used as given; otherwise the app estimates.
- The estimate counts calories above resting: `(MET - 1) x weight in kg x hours`, using the user's latest logged weight (170 lb when none is logged) and a fixed table of effort multipliers per activity and intensity. The multipliers are standard published values recalled from memory, so estimates are approximate and labelled as estimates.
- Today's calorie ring shows net calories (eaten minus counted burn) with eaten and burned shown beneath.
- A per-user setting says what share of workout calories counts (default 100%), because estimates tend to run high.
- Workout calories are presented neutrally as "burned", never as a reward or a debt.

## Out of scope

Distance, speed, power and heart-rate fields; importing ride files; weekly workout goals or streaks.
